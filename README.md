<a id="설치·실행방법"></a>
## ⚙️ 설치·실행방법
> ### 프로젝트 클론
> ```bash
> git clone https://github.com/yeojinhub/sistJava.git
> cd sistJava/java_se
> ```
> 
> ### JDK 17 설치 확인
> ```bash
> java -version
> # java version "17.x.x"
> ```
>
> ### IDE에서 프로젝트 열기
> ```
> "Import → Existing Projects” 또는 “File → Open"
> 빌드 경로를 JDK 17로 지정
> ```
> 
> ### 애플리케이션 실행
> ```
> Run as Java Application
> ```
